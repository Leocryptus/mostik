# Мостик — личная ОС Лео

ERP, задачи, цели и штаб агентов в одном ядре. Тёмный интерфейс «Токио, ночь».

## Запуск

```bash
npm run dev     # разработка, http://localhost:8793
npm run build   # сборка
npm run start   # прод, слушает 0.0.0.0:8793 (доступ с телефона через Tailscale)
```

## База

SQLite через Prisma. Схема — `prisma/schema.prisma`.

```bash
npm run db:push    # применить схему
npm run db:studio  # посмотреть данные
```
