# Мостик — личная ОС Лео

ERP, задачи, цели и штаб агентов в одном ядре. Тёмный интерфейс «Токио, ночь».

## Запуск

```bash
npm run dev     # разработка, http://localhost:8793
npm run build   # сборка
npm run start   # прод, слушает 0.0.0.0:8793 (доступ с телефона через Tailscale)
```

## База

SQLite через Prisma. Схема — `prisma/schema.prisma`.

```bash
npm run db:push    # применить схему
npm run db:studio  # посмотреть данные
```

## Канон

Техническое задание и решения — в волте: `Проекты/ОС Лео — Капитанский мостик/`
(ТЗ v3.0, аудит от 25.07, дизайн утверждён 27.07, tasks.json — 63 тикета).

Правила стройки: одна итерация — одна задача, тест раньше кода для любых формул,
«готово» говорим только после проверки.

## Что в репозитории, а что нет

Репозиторий открытый, поэтому личных данных в нём нет:

- настоящие проекты, люди и суммы — в `scripts/seed.data.local.ts`, он не коммитится;
  в репозитории лежит `seed.data.example.ts` с обезличенным примером;
- база (`prisma/dev.db`), бэкапы и `.env` — только локально;
- демо-данные на витрине стиля выдуманы.

Чтобы поднять у себя:

```bash
npm install
cp .env.example .env          # укажи путь к своей базе
npm run db:push               # создать таблицы
npx tsx scripts/seed.ts       # заполнить примером
npm run dev                   # http://localhost:8793
```
